# Finding 09: Directory Listing

| Item | Detail |
|------|--------|
| **Kerentanan** | Directory Listing / Directory Browsing |
| **Severity** | Low |
| **Skor CVSS** | 3.7 (`CVSS:4.0/AV:L/AC:L/AT:N/PR:N/UI:N/VC:L/VI:N/VA:N/SC:N/SI:N/SA:N`) |
| **Endpoint / Path** | `GET /uploads/`, `GET /backup/`, `GET /assets/` |

---

## Deskripsi

Directory Listing terjadi ketika server web dikonfigurasi untuk menampilkan daftar seluruh isi berkas dan folder di dalam suatu direktori saat file indeks default (seperti `index.html` atau `index.php`) tidak ditemukan. Hal ini memberikan informasi struktur direktori internal aplikasi kepada publik secara cuma-cuma.

---

## Dampak

- **Information Disclosure:** Penyerang dapat melihat dan mengunduh berkas-berkas internal, skrip cadangan, file log, atau berkas unggahan pengguna lain yang tidak seharusnya dapat diakses publik.
- **Memudahkan Reconnaissance:** Struktur direktori yang terlihat memudahkan penyerang dalam pemetaan aplikasi dan pencarian celah keamanan tambahan.

---

## Rekomendasi Perbaikan

- **Nonaktifkan Directory Indexing:** Matikan fitur pengindeksan direktori pada server web secara menyeluruh.
- **Tambahkan Berkas Index Kosong:** Letakkan berkas `index.html` atau `index.php` kosong di setiap direktori publik sebagai langkah perlindungan tambahan.

### Contoh Konfigurasi Server

```apache
# Apache (.htaccess / httpd.conf)
Options -Indexes
```

```nginx
# Nginx (nginx.conf)
location /uploads/ {
    autoindex off;
}
```
