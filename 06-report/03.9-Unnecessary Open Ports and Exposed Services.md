# Finding 07: Unnecessary Open Ports & Exposed Services

| Item | Detail |
|------|--------|
| **Kerentanan** | Unnecessary Open Ports & Exposed Administrative Services |
| **Severity** | Medium |
| **Skor CVSS** | 6.9 (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:L/VI:L/VA:N/SC:N/SI:N/SA:N`) |
| **Port / Service** | `22/tcp` (SSH), `3306/tcp` (MySQL Database) |

---

## Deskripsi

Kerentanan ini terjadi karena server membuka port layanan sensitif dan administratif langsung ke jaringan publik tanpa adanya pembatasan akses (*firewalling*). Layanan seperti database MySQL (`3306`) atau remote access SSH (`22`) yang seharusnya hanya dapat diakses secara lokal atau melalui VPN internal kini dapat dijangkau oleh siapapun dari luar.

---

## Dampak

- **Brute Force & Password Spraying:** Penyerang dapat melakukan percobaan login secara masif (*brute force attack*) terhadap port SSH atau MySQL.
- **Eksploitasi Celah Service:** Jika versi layanan yang berjalan memiliki kerentanan yang diketahui (*CVE*), penyerang dapat langsung mengeksploitasinya dari luar.
- **Akses Langsung ke Database:** Memungkinkan percobaan koneksi database langsung dari luar jika terdapat kelemahan otentikasi.

---

## Rekomendasi Perbaikan

- **Terapkan Firewall Rules:** Gunakan `ufw` atau `iptables` untuk memblokir port `3306` dan membatasi port `22` (SSH) hanya untuk IP tepercaya (*IP Whitelisting*).
- **Bind Database ke Loopback:** Konfigurasikan MySQL agar hanya mendengarkan koneksi lokal (`bind-address = 127.0.0.1`).
- **Gunakan VPN:** Seluruh akses manajemen server (SSH/DB) harus diakses melalui saluran terisolasi (*Virtual Private Network* / VPN).

### Contoh Konfigurasi

```bash
# UFW Firewall Rules (Ubuntu/Debian)
sudo ufw default deny incoming
sudo ufw allow 80/tcp
sudo ufw allow 8083/tcp
sudo ufw allow from 192.168.56.1 to any port 22 proto tcp
sudo ufw enable
```

```ini
# MySQL Configuration (/etc/mysql/mysql.conf.d/mysqld.cnf)
[mysqld]
bind-address = 127.0.0.1
```

## Langkah Proof of Concept (PoC)

### Langkah 1 — Melakukan pemindaian port menggunakan Nmap

**Command:**

```bash
nmap -p 22,80,3306,8083 192.168.56.105
```

**Output Nmap:**

```text
PORT     STATE SERVICE
22/tcp   open  ssh
80/tcp   open  http
3306/tcp open  mysql
8083/tcp open  us-srv
```

> **[Capture Hasil Scan Nmap Menampilkan Port 22 dan 3306 Open]**

---

### Langkah 2 — Mencoba koneksi remote langsung ke port MySQL (3306)

**Command:**

```bash
mysql -h 192.168.56.105 -u root -p
```

> **[Capture Prompt Login MySQL Terbuka dari Jaringan Publik]**
